# Kruger & Victoria Falls – reisplanner 2027

Generieke, Nederlandstalige, mobile-first reisplanner (statische site, GitHub Pages) voor ±3 weken Zuid-Afrika (Panorama Route, Kruger, private reserves) en Zimbabwe (Victoria Falls, optioneel Chobe) in het droge seizoen.

- Alle feiten met bronlink; ⚠️ = onzeker of alleen secundaire bron. Laatst gecontroleerd: 13 oktober 2026.
- Kaart: Leaflet + OpenStreetMap; rijroutes via OSRM.
- Offline: service worker (zelfde aanpak als ieper-loopgravenkaart).
